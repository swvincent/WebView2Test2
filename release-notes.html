Version 4.2.0 — May 15, 2026

Highlights

  • Introduced real-time collaboration mode allowing multiple users to edit documents simultaneously
  • New dashboard layout with customizable widget panels
  • Added dark mode support across the entire application

New Features

  • Export to PDF now supports custom page sizes and margins
  • Added keyboard shortcut cheat sheet accessible via Ctrl+?
  • Notification preferences can now be configured per-project
  • Search results now include a preview snippet

Bug Fixes

  • Fixed crash when opening files larger than 50 MB
  • Resolved issue where undo history was lost after auto-save
  • Fixed incorrect timestamp display in timezones east of UTC+9
  • Corrected tab order in the settings dialog

Performance

  • Reduced initial load time by approximately 30% through lazy loading of secondary modules
  • Improved scroll performance in long documents

Version 4.1.2 — April 28, 2026

Bug Fixes

  • Fixed a regression in 4.1.1 that prevented saving files on network drives
  • Resolved authentication loop when session tokens expired mid-session
  • Fixed missing border on selected items in the file tree
  • Corrected broken link in the onboarding wizard

Improvements

  • Error messages now include a support reference code for faster troubleshooting
  • Updated bundled certificates to resolve TLS warnings on certain corporate networks

Version 4.1.1 — April 10, 2026

Bug Fixes

  • Fixed drag-and-drop not working in Firefox 136 and later
  • Resolved duplicate entries appearing in the recent files list
  • Fixed tooltip text overlapping the toolbar on smaller screen resolutions

Version 4.1.0 — March 22, 2026

Highlights

  • All-new comment and annotation system with threaded replies
  • Bulk operations now available in the file manager

New Features

  • Added support for importing from CSV and TSV formats
  • Users can now set a custom accent color in appearance settings
  • Activity log now exportable as a plain-text report
  • Added --headless flag for CLI batch processing

Bug Fixes

  • Fixed race condition that occasionally corrupted auto-saved drafts
  • Resolved issue where column widths reset after sorting
  • Fixed broken pagination on the audit log page when filtering by user
  • Corrected focus trap behavior in modal dialogs for screen reader users

Deprecations

  • The legacy XML import format is deprecated and will be removed in version 5.0
  • The /api/v1/export endpoint is deprecated; use /api/v2/export instead

Version 4.0.0 — February 3, 2026

Highlights

  • Major UI redesign with improved information density and navigation
  • Rebuilt core data engine for significantly faster queries on large datasets
  • Plugin API v2 with expanded hooks and a new sandboxed execution model

Breaking Changes

  • Plugin API v1 is no longer supported; all plugins must migrate to v2
  • Configuration file format has changed from INI to TOML — see the migration guide
  • Minimum supported OS versions updated: Windows 10, macOS 13, Ubuntu 22.04

New Features

  • Role-based access control with fine-grained permission scopes
  • Native ARM64 builds for macOS and Linux
  • Integrated changelog viewer showing version history within the app
  • Two-factor authentication now required for admin accounts

Bug Fixes

  • Fixed long-standing issue where special characters in file names caused export failures
  • Resolved memory leak in the chart rendering component
  • Fixed incorrect totals when applying multiple filters simultaneously

Performance

  • Query execution time reduced by up to 60% on indexed tables
  • Startup time improved by deferring plugin initialization until first use
  • Reduced peak memory usage during large file imports by 40%
